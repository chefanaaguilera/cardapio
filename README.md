# Cardápio da Ana Aguilera

Site estático do cardápio especial de Natal da Ana Aguilera.

## Acessar o site

[chefanaaguilera.github.io/cardapio](https://chefanaaguilera.github.io/cardapio/)

## Publicar alterações

O GitHub Pages publica o conteúdo da pasta raiz da branch `main` automaticamente. Como o site é estático, não é necessário executar uma etapa de build.

1. Edite o arquivo `index.html`.
2. No terminal, na pasta do projeto, registre e envie as alterações:

   ```bash
   git add index.html
   git commit -m "Atualiza o cardápio"
   git push origin main
   ```

3. Aguarde o GitHub Pages concluir a publicação. O andamento pode ser acompanhado em **Actions**, na execução **pages build and deployment**.
4. Acesse novamente o [site publicado](https://chefanaaguilera.github.io/cardapio/) para conferir as alterações.
